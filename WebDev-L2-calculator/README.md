## Project Overview

This project is developed as part of the **Oasis Infobyte Web Development & Designing Internship – Level 2, Task 1**.

The project is a functional and responsive calculator developed using **HTML5, CSS3, and Vanilla JavaScript**. It can perform basic arithmetic operations through a simple and user-friendly interface.

## Objective

The objective of this task is to create a functional calculator using HTML, CSS, and JavaScript while practicing user interaction, calculation logic, responsive design, and event handling.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- CSS Grid
- Visual Studio Code
- Google Chrome

## Features

- Display screen for input and results
- Number buttons from 0 to 9
- Decimal number support
- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Equals (=) button
- Clear (C) button
- Backspace/Delete button
- Division-by-zero error handling
- Operator chaining
- Standard mathematical operator precedence
- Responsive design
- CSS Grid based calculator layout
- Event listeners using JavaScript
- No inline `onclick` attributes
- No use of `eval()`
